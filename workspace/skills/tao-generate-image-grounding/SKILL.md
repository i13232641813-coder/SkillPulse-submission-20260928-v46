# Image Grounding

Local SkillPulse teaching sample for the image-grounding interface. It is not
an upstream NVIDIA artifact and does not execute an image model.

## Run

The current runner returns a synthetic bounding box and a `mock://` image URI.
Do not use its result as a real detection.

## Output
Return the declared JSON/image output shape for workflow demonstration only.
